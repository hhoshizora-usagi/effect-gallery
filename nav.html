01

ハンバーガー変形

Hamburger Morph

  • HTML
  • CSS
  • JS

三本線のメニューボタンが、押すと「×」や「←」にくるっと変形する。3種類入り。

使いどころスマホ用メニューボタン・サイドバーの開閉

単体で開く ↗ 
<div class="fx-burger-row">
  <button class="fx-burger fx-burger--x" data-fx="hamburger" aria-expanded="false" aria-label="メニュー">
    <span></span><span></span><span></span>
  </button>
  <button class="fx-burger fx-burger--arrow" data-fx="hamburger" aria-expanded="false" aria-label="メニュー">
    <span></span><span></span><span></span>
  </button>
  <button class="fx-burger fx-burger--spin" data-fx="hamburger" aria-expanded="false" aria-label="メニュー">
    <span></span><span></span><span></span>
  </button>
</div>
.fx-burger-row { display: flex; gap: 32px; flex-wrap: wrap; justify-content: center; }
.fx-burger {
  position: relative;
  width: 84px;
  height: 84px;
  border: 4px solid #111;
  border-radius: 22px;
  background: #ffd400;
  cursor: pointer;
  box-shadow: 6px 6px 0 #111;
  transition: transform .5s cubic-bezier(.2, 1.4, .4, 1), background .3s;
}
.fx-burger--arrow { background: #00c2ff; }
.fx-burger--spin  { background: #ff3d7f; }
.fx-burger span {
  position: absolute;
  left: 20px;
  width: 36px;
  height: 5px;
  border-radius: 9px;
  background: #111;
  transition: transform .4s cubic-bezier(.2, 1.4, .4, 1), opacity .2s, width .3s, top .3s;
}
.fx-burger span:nth-child(1) { top: 26px; }
.fx-burger span:nth-child(2) { top: 37.5px; }
.fx-burger span:nth-child(3) { top: 49px; }

/* × に変形 */
.fx-burger--x[aria-expanded="true"] span:nth-child(1) { top: 37.5px; transform: rotate(45deg); }
.fx-burger--x[aria-expanded="true"] span:nth-child(2) { opacity: 0; transform: translateX(-20px); }
.fx-burger--x[aria-expanded="true"] span:nth-child(3) { top: 37.5px; transform: rotate(-45deg); }

/* ← に変形 */
.fx-burger--arrow[aria-expanded="true"] span:nth-child(1) { width: 22px; transform: translate(-3px, 7px) rotate(-40deg); }
.fx-burger--arrow[aria-expanded="true"] span:nth-child(3) { width: 22px; transform: translate(-3px, -7px) rotate(40deg); }

/* 回転しながら × に */
.fx-burger--spin[aria-expanded="true"] { transform: rotate(180deg); background: #7cff4f; }
.fx-burger--spin[aria-expanded="true"] span:nth-child(1) { top: 37.5px; transform: rotate(45deg); }
.fx-burger--spin[aria-expanded="true"] span:nth-child(2) { transform: scaleX(0); }
.fx-burger--spin[aria-expanded="true"] span:nth-child(3) { top: 37.5px; transform: rotate(-45deg); }
// 押すたびに aria-expanded を true / false に切りかえる（見た目は CSS が担当）
(() => {
  document.querySelectorAll('[data-fx="hamburger"]').forEach((btn) => {
    btn.addEventListener('click', () => {
      const open = btn.getAttribute('aria-expanded') !== 'true';
      btn.setAttribute('aria-expanded', String(open));
      btn.setAttribute('aria-label', open ? 'メニューを閉じる' : 'メニュー');
    });
  });
})();

03

すべるピル

Sliding Pill

  • HTML
  • CSS
  • JS

メニューの後ろの丸い色の板が、マウスを乗せた項目へスーッとすべって移動する。

使いどころタブ切り替え・ヘッダーメニュー・カテゴリー選択

単体で開く ↗ 
<nav class="fx-pill" data-fx="pill-indicator">
  <span class="fx-pill__bg" aria-hidden="true"></span>
  <a href="#" class="is-active">ALL</a>
  <a href="#">MUSIC</a>
  <a href="#">FOOD</a>
  <a href="#">ART</a>
</nav>
.fx-pill {
  position: relative;
  display: flex;
  gap: 4px;
  padding: 6px;
  border: 3px solid #111;
  border-radius: 999px;
  background: #fff;
  box-shadow: 6px 6px 0 #111;
}
.fx-pill a {
  position: relative;
  z-index: 1;
  padding: 10px clamp(12px, 3vw, 22px);
  color: #111;
  font-size: clamp(14px, 3.6vw, 20px);
  text-decoration: none;
  transition: color .3s;
}
.fx-pill a.is-hover { color: #fff; }
.fx-pill__bg {
  position: absolute;
  top: 6px;
  bottom: 6px;
  left: 0;
  width: 0;
  border-radius: 999px;
  background: #ff3d7f;
  transition: transform .45s cubic-bezier(.2, 1.3, .4, 1), width .45s cubic-bezier(.2, 1.3, .4, 1), background .3s;
}
// マウスを乗せた項目の位置と幅に、後ろの板を合わせる
(() => {
  const colors = ['#ff3d7f', '#00c2ff', '#ff7a00', '#a259ff', '#7cff4f'];
  document.querySelectorAll('[data-fx="pill-indicator"]').forEach((nav) => {
    const bg = nav.querySelector('.fx-pill__bg');
    const links = [...nav.querySelectorAll('a')];
    const moveTo = (a) => {
      links.forEach((l) => l.classList.toggle('is-hover', l === a));
      bg.style.width = `${a.offsetWidth}px`;
      bg.style.transform = `translateX(${a.offsetLeft}px)`;
      bg.style.background = colors[links.indexOf(a) % colors.length];
    };
    const home = () => moveTo(nav.querySelector('.is-active') || links[0]);
    links.forEach((a) => {
      a.addEventListener('mouseenter', () => moveTo(a));
      a.addEventListener('focus', () => moveTo(a));
      a.addEventListener('click', (e) => {
        e.preventDefault();                       // 見本ではページ移動しない
        links.forEach((l) => l.classList.remove('is-active'));
        a.classList.add('is-active');
      });
    });
    nav.addEventListener('mouseleave', home);
    addEventListener('resize', home);
    home();
  });
})();

04

かくれるヘッダー

Hide on Scroll

  • HTML
  • CSS
  • JS

下にスクロールするとヘッダーがスッと隠れて、上に戻すとまた出てくる。画面を広く使える。

使いどころスマホサイト・ブログ・長いページのヘッダー

単体で開く ↗ 
<header class="fx-hh" data-fx="hide-header">
  <b class="fx-hh__logo">EPIC DAY</b>
  <nav class="fx-hh__nav"><a href="#">LINEUP</a><a href="#">TICKET</a></nav>
</header>

<!-- ↓ スクロールを試すためのダミーの中身 -->
<section class="demo-block">下へスクロール ↓</section>
<section class="demo-block demo-block--pink">ヘッダーが隠れた！</section>
<section class="demo-block demo-block--yellow">上へ戻すと…</section>
<section class="demo-block demo-block--cyan">また出てくる！</section>
.fx-hh {
  position: fixed;
  top: 0;
  left: 0;
  right: 0;
  z-index: 100;
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 14px 20px;
  background: #ffd400;
  color: #111;
  border-bottom: 4px solid #111;
  transition: transform .4s cubic-bezier(.2, .9, .3, 1), box-shadow .3s;
}
.fx-hh.is-hidden { transform: translateY(-110%); }
.fx-hh.is-scrolled { box-shadow: 0 8px 0 rgba(0, 0, 0, .25); }
.fx-hh__logo { font-size: 22px; font-weight: normal; }
.fx-hh__nav { display: flex; gap: 18px; }
.fx-hh__nav a { color: #111; text-decoration: none; }
// 前回のスクロール位置と比べて、下に動いたら隠す・上に動いたら出す
(() => {
  document.querySelectorAll('[data-fx="hide-header"]').forEach((header) => {
    let lastY = scrollY;
    addEventListener('scroll', () => {
      const y = scrollY;
      const down = y > lastY && y > header.offsetHeight;   // 一番上では隠さない
      if (Math.abs(y - lastY) > 4) header.classList.toggle('is-hidden', down);
      header.classList.toggle('is-scrolled', y > 10);
      lastY = y;
    }, { passive: true });
  });
})();

ボタンを押すと、丸い色がぶわっと画面いっぱいに広がって、大きなメニューが順番に飛び出す。

使いどころブランドサイト・イベントサイトのメニュー

単体で開く ↗ 
<button class="fx-om-btn" data-fx="overlay-menu" aria-expanded="false" aria-controls="fx-om">MENU</button>

  <a href="#" style="--i: 1">LINEUP</a>

  -webkit-text-stroke: 2px #111;
  text-shadow: 5px 5px 0 #111;
  opacity: 0;
  transform: translateY(40px) rotate(-6deg);
  transition: opacity .3s, transform .5s cubic-bezier(.2, 1.6, .4, 1), color .2s;

.fx-om.is-open a {
  opacity: 1;
  transform: none;
  transition-delay: calc(.3s + var(--i) * .07s);
}
.fx-om a:hover { color: #ffd400; }
// ボタンでメニューを開け閉め（Esc キーでも閉じる）
(() => {
  document.querySelectorAll('[data-fx="overlay-menu"]').forEach((btn) => {
    const menu = document.getElementById(btn.getAttribute('aria-controls'));
    const set = (open) => {
      btn.setAttribute('aria-expanded', String(open));
      btn.textContent = open ? 'CLOSE' : 'MENU';
      menu.classList.toggle('is-open', open);
      menu.setAttribute('aria-hidden', String(!open));
    };
    btn.addEventListener('click', () => set(btn.getAttribute('aria-expanded') !== 'true'));
    addEventListener('keydown', (e) => { if (e.key === 'Escape') set(false); });
    menu.addEventListener('click', (e) => { if (e.target.closest('a')) { e.preventDefault(); set(false); } });
  });
})();
